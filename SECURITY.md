# Security Policy

## Supported Version

Version 1.0.0 is the current training release.

## Security Principles

- Least privilege
- Localhost-only network binding
- Isolated public document directory
- Restricted configuration access
- Protected operational logs
- Verified backup integrity
- Automated permission auditing

## Sensitive Data

Do not commit credentials, private configuration,
runtime logs, private keys or backup archives.

## Reporting

Report suspected vulnerabilities privately to
the repository maintainer.

Avoid publishing sensitive exploitation details.

## Deployment Warning

This repository is a local educational environment.
Do not expose its development HTTP server directly
to the public internet.
